개인정보처리방침

그날의 탈출 업로더 · 시행일 2026년 11월 11일

"그날의 탈출 업로더"(이하 "이 도구")는 유튜브 채널 그날의 탈출의 운영자가 자기 채널을 관리하려고 만든 개인용 도구입니다. 운영자 본인만 사용하며, 일반에 배포하지 않습니다.

1. 접근하는 정보

이 도구는 YouTube API 서비스를 통해, 로그인한 채널 운영자 본인의 유튜브 채널에만 접근합니다.

  • 채널 정보(이름, 설명, 키워드, 배너, 재생목록)를 읽고 고칩니다.
  • 운영자가 만든 영상, 썸네일, 자막을 그 채널에 올립니다.

다른 사람의 계정이나 개인정보에는 접근하지 않으며, 시청자의 정보를 수집하지 않습니다.

2. 저장과 보관

구글 로그인으로 받은 인증 정보(OAuth 토큰)는 운영자 본인의 컴퓨터에만 저장됩니다. 이 도구는 따로 서버를 두지 않으며, 어떤 정보도 외부 서버에 보관하지 않습니다.

3. 제3자 제공

이 도구는 접근한 정보를 누구에게도 제공하거나 판매하지 않습니다. 정보는 운영자의 컴퓨터와 구글(YouTube) 사이에서만 오갑니다.

4. 접근 권한 철회

운영자는 언제든지 구글 계정의 보안 설정에서 이 도구의 접근 권한을 철회할 수 있고, 컴퓨터에 저장된 인증 정보 파일을 지워 사용을 중단할 수 있습니다.

5. YouTube API 서비스

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, 구글이 정보를 처리하는 방식은 Google 개인정보처리방침을 따릅니다.

6. 문의

문의는 이 페이지 저장소의 이슈에 남겨 주세요.

Privacy Policy

Geunal Escape Uploader · Effective November 11, 2026

"그날의 탈출 업로더" (Geunal Escape Uploader, "the tool") is a personal tool made by the owner of the YouTube channel "그날의 탈출" to manage their own channel. Only the channel owner uses it; it is not distributed to the public.

  • Information accessed. Through YouTube API Services, the tool accesses only the signed-in owner's own YouTube channel: it reads and updates channel settings (description, keywords, banner, playlists) and uploads the owner's own videos, thumbnails and captions. It does not access other people's accounts and does not collect viewer data.
  • Storage. OAuth credentials are stored only on the owner's own computer. The tool has no server and stores nothing on external servers.
  • Sharing. The tool does not share or sell any information. Data moves only between the owner's computer and Google (YouTube).
  • Revoking access. Access can be revoked at any time from the Google security settings page, and the locally stored credential file can be deleted.
  • YouTube API Services. The tool uses YouTube API Services. By using it, the user agrees to be bound by the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.
